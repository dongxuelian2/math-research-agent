# Production Module Map

## Boundary

This map describes the implementation at baseline HEAD 3229aced9fa9bcae41c5ddfea6b6291a6e68d725. It distinguishes coordination from authority. The presence of a validator or immutable record is recorded as code evidence; no row is an independent certification.

## Plane summary

| Plane | Primary owner | Durable representation | Semantic role |
|---|---|---|---|
| Project truth | ProjectStore, TruthStoreFacade | project.json, theorems/*.json, truth/ snapshots, mutation intents/receipts | theorem lifecycle and ClaimSnapshot identity |
| Research | ResearchStoreFacade | research/maps, obligations, directives, tactical sessions, closures, failure records | non-authoritative frontier and evidence scope |
| Execution | SQLiteRuntimeBackend and RuntimeEffectCoordinator | runtime/control.sqlite3 plus journal/outbox/attempt/result/effect tables | durable dispatch, fencing, accepted results, exactly-once effect slots |
| Artifact | RuntimeArtifactStore, Phase7Store, project run writers | content-addressed files and JSON manifests | byte provenance and Phase 7 closure artifacts |
| Governance | GovernanceController and architecture types | research/governance immutable objects and projections | review clock, probe, patch, critic, authorization |
| Provider/presentation | Router, provider clients, OpenProver adapter | run archives, typed sidecars, usage and routing state | transport and typed response boundary; not truth authority |

## High-value call relationships

1. CLI or campaign CLI reaches ResearchOrchestrator.
2. ResearchOrchestrator initializes TruthStoreFacade, SQLiteRuntimeBackend, ModelRouter, pipeline scheduler, ResearchStoreFacade, GovernanceController, and Phase7Store.
3. CandidateEngine invokes the upstream Prover through RoutedLLMClient; OpenProver adapter materializes typed worker events.
4. AuditCoordinator invokes specialist/final auditor roles; AuditGate is assembled from typed results and local policy.
5. A successful orchestrator run closes a TacticalSession, resolves ResearchMap obligations, builds RootSynthesis, builds FinalConsolidation, creates TruthMutationIntent, applies the truth transition through RuntimeEffectCoordinator, and closes PromotionClosure.
6. A failed run writes FailureMap/route-failure evidence and records research/governance effects through the runtime effect coordinator.
7. Resume reconstructs from state.json, claim snapshots, map projections, campaign projections, SQLite reconciliation, and immutable artifacts; it must not carry live futures or provider handles across a process boundary.

## Cross-cutting failure behavior

The implementation generally uses strict schema/envelope loaders, content hashes, immutable files, CAS/version checks, lease/generation fencing, and explicit blocked/manual-review states. The residual audit questions are not whether these mechanisms exist, but whether every public path invokes the correct validator in the correct order and whether multi-process/filesystem crash boundaries are proven independently.
